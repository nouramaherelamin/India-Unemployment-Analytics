# Labour Market Shockwaves — Final Report

## Project Status

All 12 planned phases are complete.

### Main Result

Mean unemployment increased from **9.508%** before COVID to **17.780%** during the COVID period, a change of **+8.272 percentage points**.

### Important Limitation

The dataset contains only **14 monthly observations**, including a major COVID structural shock. Forecasting is therefore scoped to short-horizon benchmark diagnostics.
