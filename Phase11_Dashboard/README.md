# India Unemployment Analytics — Themed Dashboard

Redesigned Streamlit dashboard using the supplied India-themed visual assets while keeping the project's actual analytical data.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app uses bundled relative `data/` and `assets/` folders.

## Design

Deep emerald sidebar, saffron active navigation, navy typography, India flag wave, India landmark hero, supplied KPI/section icons, and white analytical cards.

The redesign changes presentation only; the underlying project data and analytical outputs remain the same.
