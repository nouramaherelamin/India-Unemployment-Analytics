# Phase 13 — Complete Project Jupyter Notebook

This folder contains the complete reproducible Jupyter Notebook for the India unemployment analysis project.

## Structure

- `India_Unemployment_Complete_Project_Phase13.ipynb` — complete notebook
- `data/Unemployment in India(1).csv` — original project dataset
- `requirements.txt` — required Python packages

## Run

From the project root:

```bash
pip install -r requirements.txt
jupyter notebook
```

Open:

`India_Unemployment_Complete_Project_Phase13.ipynb`

Then use **Run All**.

The notebook uses the relative dataset path:

```python
data/Unemployment in India(1).csv
```

No absolute local Windows path is required.
